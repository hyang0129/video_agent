# Assets Directory

This directory contains static media assets used across video productions.

## Background Music

### default_music.mp3
- **Track**: "Pixel Peeker Polka - slower" by Kevin MacLeod
- **Source**: https://incompetech.com/music/royalty-free/music.html
- **License**: Creative Commons Attribution 4.0 International
- **License URL**: http://creativecommons.org/licenses/by/4.0/
- **Usage**: Default background music for all videos (Phase 1)
- **Duration**: ~3 minutes (loops as needed)
- **Style**: Upbeat, energetic, works well for educational/informative content

**Attribution Required**:

## Download Instructions

To download the placeholder music:

1. Visit: https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1100774
2. Search for "Pixel Peeker Polka - slower"
3. Download MP3 format
4. Save as `assets/default_music.mp3`

**Alternative**: Use any Creative Commons or royalty-free track you prefer. Just update this README with proper attribution.
